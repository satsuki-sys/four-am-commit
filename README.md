## What it does

`main.py` (stdlib only, Python 3.13) writes one line — the commit message —
to `/output/entry.txt`:

> fix: the bug was inside the fix for the bug, which was inside the fix for the bug; at 4am I stopped counting and committed anyway

## Run it

```sh
python3 main.py
```

It writes to `/output/entry.txt` by default; set `OUTPUT_DIR` to write
elsewhere (e.g. `OUTPUT_DIR=./output python3 main.py`).
